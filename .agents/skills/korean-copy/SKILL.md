# 한국어 문구

이 스킬이 COPY-01 의 정본이다. 대상은 사이트 UI 문구(헤더 `src/layouts/Base.astro`, `src/**/*.astro`, `src/components/SearchUi.astro` 의 검색 번역)와 README 다. 블로그 글 본문은 작성자의 글이라 대상이 아니다.

## 규칙

- **어조**: 사이트 UI 는 합니다체, README·개발 문서는 한다체. 한 화면 안에서 섞지 않는다. 독자에게 말을 거는 화면은 공손하게, 규칙을 적는 문서는 짧게 하려는 것이다.
- **번역투를 쓰지 않는다**: 영어를 옮긴 티가 나는 표현 대신 한국 서비스(네이버·카카오·velog)가 실제로 쓰는 말을 쓴다.

  | 피할 것                            | 쓸 것                |
  | ---------------------------------- | -------------------- |
  | `X에 대한 결과`                    | `'X' 검색 결과`      |
  | `다음 검색어를 시도해 보세요`      | `추천 검색어`        |
  | `N분 분량`                         | `읽는 데 N분`        |
  | `N개 선택`(상태인데 동작처럼 읽힘) | `N개 선택됨`         |
  | `~가 필요합니다`                   | `~하려면 ~해 주세요` |

- **상태와 동작을 구분한다**: 버튼·aria-label 은 누르면 일어나는 일(`테마 전환`, `댓글 보기`, `페이지 이동`)을 쓴다.

## 용어집

같은 개념은 한 용어로 쓴다.

| 개념                       | 쓸 말                                                       |
| -------------------------- | ----------------------------------------------------------- |
| post                       | 글                                                          |
| archive / category / tag   | 아카이브 / 카테고리 / 태그                                  |
| release(버전 공개)         | 릴리스                                                      |
| update                     | 업데이트                                                    |
| search index               | 검색 인덱스                                                 |
| build output               | 빌드 결과물                                                 |
| merge, PR, CI, push, alias | 영어 그대로(머지, PR, CI, push, alias)                      |
| 제품 이름                  | 원어 그대로(GitHub, GitHub Pages, YouTube, JavaScript, RSS) |
| Super Famicom / SNES       | 슈퍼 패미콤(「패미컴」 금지). 줄임말·주소·식별자는 SFC      |

## 확인

1. **빌드하고 e2e 를 돌린다** — `pnpm build && pnpm test:e2e`. e2e 는 `dist/` 를 검사하므로 빌드를 빼면 옛 문구를 검사한다. 버튼 이름(aria-label)으로 요소를 찾는 테스트가 있어, 이름이 바뀌면 `e2e/site.spec.ts` 도 함께 고친다.
   완료: e2e 통과.
2. **PR 로 올린다** — [git-workflow](../git-workflow/SKILL.md).
   완료: `ci-ok` 초록.
